# Welcome to Obsidian.GG

**Obsidian.GG** is a modern FiveM roleplay community focused on immersive storytelling, quality gameplay, and a welcoming community experience.

Our goal is to build a platform that extends beyond the game itself—combining a custom web application, Discord integration, documentation, and future gameplay services into a unified ecosystem.

---

## Our Projects

### 🌐 Obsidian.GG Web

The official community website built with Next.js.

Features include:

* Discord authentication
* Member dashboard
* Documentation platform
* Future FiveM integration
* Community announcements

### 🎮 Obsidian.GG Server

The FiveM server powering the roleplay experience.

Planned features include:

* Character management
* Server integrations
* Economy systems
* Quality-of-life improvements
* Administrative tooling
